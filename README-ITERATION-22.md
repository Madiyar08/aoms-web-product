# AOMS 2.0 — Iteration 22

## Складской модуль: первая рабочая основа

- Справочник материалов: SKU, название, единица измерения, минимальный остаток.
- Журнал приходов и расходов с сотрудником, датой и основанием.
- Остаток рассчитывается из движений, а не редактируется напрямую.
- Расход выше доступного остатка блокируется.
- Архивирование позиции мягкое; история операций остаётся.
- Серверные действия требуют `warehouse:write`; чтение — `warehouse:read`.
- События создания позиции, прихода, расхода и архивирования добавляются в Audit Log.

## Ограничения

- Нет автоматической выдачи материалов экипажам, инвентаризации, закупок, поставщиков или бухгалтерской интеграции.
- Корректировки остатка намеренно отключены до отдельного процесса инвентаризации.
- UI и production build не подтверждены без полного набора зависимостей.
- Данные склада создаются в новых таблицах SQLite `warehouse_items` и `warehouse_movements`; старые таблицы не меняются.
