# AOMS 2.0 — Iteration 26: карта мониторинга

## Что добавлено

- В экран `/monitoring` встроена интерактивная карта на Leaflet с базовой картой OpenStreetMap.
- На карту выводятся ATM из действующего реестра с числовыми координатами в контрольном диапазоне; фиктивные координаты не создаются.
- Цвет точки показывает наличие отчёта за текущий день (зелёный), отсутствие отчёта (янтарный) или открытую проблему, зарегистрированную сегодня (красный).
- Географические фильтры региона и района применяются и к карте.
- Если для района уже сохранён полигон из `district_boundaries` (3 и более точек), он отображается контуром. Центры районов из одной точки не выдаются за границу.
- Из popup можно перейти в карточку ATM.
- Карта подстраивается под доступную ширину и высоту экрана; при отсутствии координат выводится понятное пустое состояние.

## Источники и ограничения

- Точки берутся из SQLite-реестра ATM, отчёты — из записей за текущую дату Ташкента, проблемы — из зарегистрированных сегодня неразобранных записей.
- Контуры районов не загружаются автоматически и не подменяются приблизительными полигонами. Используются только геометрии, уже сохранённые администратором.
- В этой итерации не добавлялась государственная граница Узбекистана: для неё требуется проверенный официальный GeoJSON-источник и отдельная процедура обновления.
- Подложка OpenStreetMap требует доступа браузера к тайловому серверу OSM. При недоступности внешней сети подложка может не загрузиться; данные ATM остаются в реестре.
- Контрольный диапазон координат — грубая проверка некорректных значений, а не точная проверка попадания внутрь государственной границы.
