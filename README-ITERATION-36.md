# Iteration 36 — отчётность: антифрод и качество GPS

## Изменения
- В отчёты по экипажам добавлены отдельные счётчики сигналов `antifraudResult=review`, `gpsQuality=low_accuracy` и `gpsQuality=unavailable`.
- Добавлены сводные карточки и столбцы таблицы на странице отчётов.
- Excel-экспорт включает те же три диагностических показателя.
- Добавлен чистый helper `lib/report-quality.ts` и unit-тесты на независимый подсчёт сигналов.

## Важное ограничение модели
Текущая модель `cleaning_reports` не содержит отдельного статуса утверждения `APPROVED`/`SUBMITTED` или процесса проверки обычных отчётов очистки. Поэтому Iteration 36 НЕ объявляет отчёты утверждёнными и НЕ меняет формулу KPI: существующий процент остаётся расчётом по факту полученных отчётов и остановок. В интерфейсе добавлено явное предупреждение об этом ограничении. Для строгого правила BR-011 потребуется отдельный workflow утверждения и безопасная миграция схемы.
