# AOMS 2.0 — Iteration 28: безопасный импорт и конфликты ID

## Что изменено
- Предварительная проверка Excel теперь выявляет повторяющиеся нормализованные ID внутри загружаемого файла.
- Предварительная проверка выявляет ID, которые уже неоднократно встречаются в текущей базе.
- Для неоднозначных ID подтверждение импорта блокируется в интерфейсе.
- Серверная операция импорта повторно проверяет конфликты и прерывает транзакцию, если обнаружены дубли. Это защищает базу даже при обходе клиентского интерфейса.
- В preview показываются конкретные ID из файла и базы.
- Существующий двухшаговый процесс с SHA-256-проверкой того же файла сохранён.
