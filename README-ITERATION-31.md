# AOMS 2.0 — Iteration 31: географическая валидация границ

## Изменения
- Серверный endpoint сохранения границ использует общий валидатор координат.
- Разрешённый формат: одна точка (ручной центр района) либо полигон из трёх и более точек; две точки отклоняются на сервере.
- Проверяются конечность координат и допустимые диапазоны широты/долготы.
- Для полигонов проверяются минимум три различные вершины, повтор соседних точек, нулевая площадь и самопересечения.
- Ошибочные границы не записываются и не могут попасть в последующую проверку района ATM.
