# Iteration 41 — серверная авторизация Server Actions

## Что исправлено

Проверка роли только на уровне отображения страницы недостаточна: Server Actions вызываются отдельными POST-запросами. Поэтому каждая изменяющая операция должна проверять право непосредственно перед работой с данными.

Добавлен общий `requireAdminPermission(permission)` в `lib/access-control.ts`. Он получает текущую административную роль и завершает операцию ошибкой при отсутствии требуемого разрешения.

Проверки добавлены в Server Actions:

- ATM: создание, изменение, удаление, массовые операции и импорт — `atms:write`.
- Расписание и маршруты: создание, удаление, повторяющиеся задания, построение и отправка маршрута — `schedule:write`.
- Экипажи/машины и проблемные ATM — `operations:write`.
- Сотрудники и изменение их ролей/Telegram-привязок — `users:manage`.
- Настройки — `settings:manage`.
- Решения по географическим кластерам — `atms:write`.
- Повторная отправка заданий очереди доставки — `operations:write`.

Складской модуль уже имел собственную серверную проверку `warehouse:write`; она сохранена.
